## ✅ **Checklist de Validation**

- [ ] Toutes les séries couvrent les **36 derniers mois** (mensuelles).
- [ ] Toutes les séries couvrent les **12 derniers trimestres** (trimestrielles).
- [ ] Aucune valeur **inventée** n’a été ajoutée.
- [ ] Les **dates** sont au format `YYYY-MM-01` (mensuel) ou `YYYY-01-01`/`YYYY-04-01` (trimestriel).
- [ ] Les **valeurs** utilisent le **point** comme séparateur décimal.
- [ ] Les **séries PMI** utilisent les bonnes sources (S&P Global pour tous sauf CNY → Caixin).
- [ ] Les **mesures d’inflation** respectent les définitions spécifiques à chaque pays.
  - EUR : HICP (global + core)
  - CAD : CPI Common, Trimmed, Median
  - AUD : Trimmed Mean, Weighted Median
  - Autres : CPI global + core
- [ ] Les **taux directeurs** sont les bons (ex: ECB Deposit Facility Rate pour EUR).
